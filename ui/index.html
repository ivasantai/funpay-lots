Управление лотами вашего аккаунта FunPay

Где взять ключ?
  1. Откройте funpay.com в браузере и войдите в аккаунт.
  2. Откройте инструменты разработчика (F12 или ⌥⌘I на Mac).
  3. Application (Chrome) / Storage (Safari, Firefox) → Cookies → https://funpay.com.
  4. Скопируйте значение cookie golden_key.
Ключ даёт полный доступ к аккаунту — не передавайте его никому. Приложение хранит его только локально.
