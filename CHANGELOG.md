# История изменений

## 1.2.0 — 2026-11-06
- Вкладка «Финансы»: балансы по валютам, история операций с фильтрами и подгрузкой, ссылки на заказы.
- Вывод средств: все способы FunPay (карта, СБП, USDT и др.), расчёт суммы к получению с комиссией, сохранённые реквизиты, предпросмотр и подтверждение с кодом 2FA.
- Автообновление: приложение само проверяет GitHub Releases, показывает новую версию и ставит её в один клик (Windows и macOS).
- Кнопка с номером версии в шапке — ручная проверка обновлений.

## 1.1.0 — 2026-11-06
- Иконка приложения для Windows (`.ico`) и macOS (`.icns`), логотип в интерфейсе.
- Документация: руководство пользователя, устройство проекта, разработка и сборка.

## 1.0.0 — 2026-11-06
- Первая версия: вход по `golden_key`, список лотов по разделам (включая неактивные), поиск и фильтры.
- Создание, редактирование, удаление, включение/выключение лотов; массовые действия.
- Редактор строится из формы FunPay, поэтому поддерживаются поля любых разделов.
- Сборки для Windows 11 x64 и macOS arm64 через GitHub Actions.
