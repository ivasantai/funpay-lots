# История изменений

## 1.6.0 — 2026-11-07
- ⚡ Автоподнятие лотов: поднимает, как только FunPay разрешает, и само ждёт нужное время; статус и «Поднять сейчас».
- ⧉ Дублирование лота и массовые правки: изменение цены (точно, на %, на сумму) и замена текста во всех выбранных лотах.
- 💾 Бэкап всех лотов в файл и восстановление (в том числе на другой аккаунт); 📋 шаблоны описаний.
- Вкладка «Заказы»: продажи с фильтрами и поиском, карточка заказа, ответ на отзыв, возврат, переход в чат; таймеры аренды с напоминаниями и автосообщением покупателю.
- Вкладка «Чаты»: переписка с покупателями прямо в приложении.
- ✨ Черновики ответов нейросетью — покупателю в чат и на отзыв.
- Вкладка «Аналитика»: выручка, продажи, средний чек, возвраты, график по дням, лучшие лоты; цены конкурентов и ваше место по цене.
- Несколько аккаунтов FunPay с переключением в один клик.
- Работа в фоне (трей на Windows), системные уведомления о заказах и сообщениях.
- Светлая/тёмная тема и горячие клавиши (Ctrl/⌘+1…5, N, F, R).

## 1.5.0 — 2026-11-06
- 🌐 Перевод на английский теперь работает и без ключа нейросети — через бесплатный переводчик MyMemory. Маркеры списков, эмодзи и переносы строк сохраняются.
- ⚙ Настройки → «Перевод на английский»: автоматически (нейросеть, если есть ключ, иначе бесплатно), всегда бесплатно или всегда нейросеть. Можно указать почту — бесплатный лимит вырастет примерно с 5 000 до 50 000 символов в день.

## 1.4.0 — 2026-11-06
- Новые сборки: macOS на Intel (`FunPayLots-macos-x86_64.zip`) и Linux x86_64 (`FunPayLots-linux-x86_64.tar.gz`). Автообновление работает и там.
- macOS: обновление больше не падает с «Read-only file system», если приложение запущено не из «Программ» (App Translocation) — новая версия ставится в настоящую папку приложения или в «Программы», карантин снимается.
- macOS: больше нет запроса «Разрешить найти устройства в локальной сети» — интерфейс загружается без внутреннего веб-сервера.
- Обновление больше не оставляет файлы `.old` рядом с приложением.
- Цены в списке лотов показываются как на сайте (без лишних знаков после запятой).
- Ошибки запуска записываются в `app.log` в папке настроек.

## 1.3.1 — 2026-11-06
- Исправлено: на Windows после автообновления новая версия иногда сразу закрывалась вместе со старой. Теперь она запускается отдельно и остаётся открытой.

## 1.3.0 — 2026-11-06
- ✨ «Заполнить с ИИ» в редакторе лота: нейросеть Claude пишет краткое и подробное описание (и по желанию сообщение покупателю после оплаты) по паре фраз о товаре, с учётом раздела, параметров лота и вашего стиля.
- 🌐 «Перевести на английский»: автоперевод русских полей лота в английскую версию с сохранением эмодзи и оформления.
- ⚙ Настройки: ключ Anthropic API для нейросети (хранится только на компьютере).

## 1.2.0 — 2026-11-06
- Вкладка «Финансы»: балансы по валютам, история операций с фильтрами и подгрузкой, ссылки на заказы.
- Вывод средств: все способы FunPay (карта, СБП, USDT и др.), расчёт суммы к получению с комиссией, сохранённые реквизиты, предпросмотр и подтверждение с кодом 2FA.
- Автообновление: приложение само проверяет GitHub Releases, показывает новую версию и ставит её в один клик (Windows и macOS).
- Кнопка с номером версии в шапке — ручная проверка обновлений.

## 1.1.0 — 2026-11-06
- Иконка приложения для Windows (`.ico`) и macOS (`.icns`), логотип в интерфейсе.
- Документация: руководство пользователя, устройство проекта, разработка и сборка.

## 1.0.0 — 2026-11-06
- Первая версия: вход по `golden_key`, список лотов по разделам (включая неактивные), поиск и фильтры.
- Создание, редактирование, удаление, включение/выключение лотов; массовые действия.
- Редактор строится из формы FunPay, поэтому поддерживаются поля любых разделов.
- Сборки для Windows 11 x64 и macOS arm64 через GitHub Actions.
