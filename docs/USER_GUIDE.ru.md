# Руководство пользователя

[English](USER_GUIDE.md) · **Русский**

## Установка

### Windows 11 (x64)
1. Скачайте `FunPayLots.exe` со страницы [Releases](https://github.com/ivasantai/funpay-lots/releases).
2. Запустите. Установка не нужна — это один файл.
3. Если SmartScreen пишет «Windows защитила ваш компьютер» (приложение не подписано сертификатом):
   «Подробнее» → «Выполнить в любом случае».

Интерфейс работает на Microsoft Edge WebView2 — в Windows 11 он уже есть.

### macOS 11 Big Sur и новее
| Мак | Файл |
|---|---|
| Apple Silicon (M1/M2/M3/M4) | `FunPayLots-macos-arm64.zip` |
| Intel | `FunPayLots-macos-x86_64.zip` |

Какой у вас мак:  → «Об этом Mac» → строка «Чип» (Apple M…) или «Процессор» (Intel).

1. Скачайте свой zip, распакуйте.
2. **Перетащите «FunPay Lots.app» в «Программы».** Это важно: если запускать прямо из «Загрузок»,
   macOS запускает приложение из временной защищённой копии (App Translocation), и туда нельзя
   поставить обновление.
3. Первый запуск: правый клик по приложению → «Открыть» → «Открыть».
   Если macOS всё равно блокирует, выполните в Терминале:
   ```bash
   xattr -dr com.apple.quarantine "/Applications/FunPay Lots.app"
   ```

Версии macOS старше 11 (Catalina и раньше) не поддерживаются.

### Linux (x86_64)
1. Скачайте `FunPayLots-linux-x86_64.tar.gz` и распакуйте:
   ```bash
   tar xzf FunPayLots-linux-x86_64.tar.gz
   ```
2. Запустите:
   ```bash
   ./FunPayLots/FunPayLots
   ```

Внутри один исполняемый файл с интерфейсом на Qt — ставить Python или Qt не нужно. Подходит для
Ubuntu 22.04+, Debian 12+, Fedora, Arch и других дистрибутивов с графическим окружением (X11 или
Wayland через XWayland). Если окно не появляется, установите системные библиотеки, которые обычно
уже есть на десктопе (пример для Ubuntu/Debian):
```bash
sudo apt install libxcb-cursor0 libxkbcommon-x11-0 libnss3 libegl1
```
Ошибки запуска пишутся в `~/.config/funpay-lots/app.log`. Сборки под ARM (Raspberry Pi и т. п.) пока нет.

## Ключ доступа (golden_key)

У FunPay нет официального API, поэтому приложение входит в аккаунт по cookie **golden_key** —
тому же, что хранит браузер после входа на сайт.

Как получить:
1. Войдите на [funpay.com](https://funpay.com) в браузере.
2. Откройте инструменты разработчика: `F12` (Windows) или `⌥⌘I` (Mac; в Safari сначала включите меню «Разработка»).
3. Chrome/Edge: **Application → Cookies → https://funpay.com**. Firefox/Safari: **Storage → Cookies**.
4. Скопируйте значение `golden_key` (32 символа из букв и цифр).

> ⚠️ Ключ даёт полный доступ к аккаунту, включая вывод денег. Никому его не передавайте.
> Если ключ утёк — выйдите из аккаунта на funpay.com и смените пароль, затем возьмите новый ключ.

Галочка «Запомнить на этом компьютере» сохраняет ключ локально, и при следующем запуске вход будет автоматическим:
- Windows: `%APPDATA%\FunPayLots\config.json`
- macOS: `~/Library/Application Support/FunPayLots/config.json`

### Несколько аккаунтов
Нажмите на ник в шапке: там список аккаунтов (переключение в один клик), **«＋ Добавить аккаунт»**
(открывает экран входа; «Отмена» возвращает к текущему) и **«Выйти из …»** — удаляет ключ текущего
аккаунта с компьютера. Автоподнятие работает для всех аккаунтов, где оно включено, а уведомления о заказах,
сообщениях и арендах — для аккаунта, который сейчас открыт.

## Работа с лотами

### Список
- Слева — разделы, где у вас есть лоты, справа — сами лоты: название, наличие, цена.
- **Поиск** ищет по названию, серверу и ID лота.
- Фильтр **Все / Активные / Неактивные**.
- **⟳ Обновить** заново загружает всё с FunPay. Изменения, сделанные на сайте, появятся после обновления.

Неактивные лоты отображаются серым. Приложение запоминает разделы, в которых видело ваши лоты, поэтому
раздел не пропадёт из списка, даже если все лоты в нём выключены.

### Включить / выключить
Переключатель в колонке «Вкл.» сразу включает или выключает лот на FunPay.

### Редактировать
Нажмите на название лота или ✎. Откроется панель с теми же полями, что и на сайте:
поля конкретного раздела (тип, сервер и т. п.), краткое и подробное описание, сообщение покупателю после
оплаты, цена, наличие, автовыдача, «Товары» для автовыдачи (по одному на строку), «Активное».
Английская версия текстов — в блоке «English version».

Поля с пометкой **«доп.»** на сайте показываются только при определённых значениях других полей.
Если FunPay требует их заполнить, он скажет об этом в ошибке после сохранения.

### Нейросеть: описание и перевод
В редакторе лота над полями есть две кнопки (нужен ключ, см. ниже):

- **✨ Заполнить с ИИ** — опишите товар парой фраз («аренда ChatGPT Plus на 3 часа, выдача сразу, +1 час за
  отзыв») и нажмите «Сгенерировать». Нейросеть напишет краткое и подробное описание, по галочке — сообщение
  покупателю после оплаты и сразу английскую версию. Учитываются раздел, параметры лота (тип, сервер…) и уже
  написанный текст — он служит примером вашего стиля, факты из него сохраняются.
- **🌐 Перевести на английский** — переводит русские поля (краткое, подробное описание, сообщение после
  оплаты) в блок «English version», сохраняя эмодзи и переносы строк. **Работает и без ключа** — через
  бесплатный переводчик MyMemory (см. ниже).

**Какой переводчик используется** — ⚙ → «Перевод на английский»:
- *Автоматически* (по умолчанию) — нейросеть, если добавлен ключ, иначе бесплатный переводчик;
- *Всегда бесплатный переводчик (MyMemory)* — без ключа и оплаты, качество проще, чем у нейросети;
- *Всегда нейросеть* — лучшее качество, нужен ключ.

У бесплатного переводчика дневной лимит: около 5 000 символов (примерно 3–6 описаний). Если указать почту
в настройках, лимит вырастет примерно до 50 000. Почта уходит только в MyMemory вместе с запросами.
Строки без русских букв (например, только эмодзи или названия на латинице) не отправляются и лимит не тратят.

Нейросеть только заполняет поля — ничего не сохраняется, пока вы не нажмёте «Сохранить». Перед сохранением
перечитайте текст: модель не знает деталей вашего товара сверх того, что вы ей написали. Ей дана
инструкция не добавлять контакты и ссылки вне FunPay (это запрещено правилами площадки), но проверять всё
равно стоит.

**Ключ нейросети.** ⚙ в шапке → «Ключ Anthropic API». Создать ключ: [console.anthropic.com](https://console.anthropic.com/settings/keys)
→ API Keys (нужна оплата по использованию на аккаунте Anthropic; одно описание обычно стоит от долей цента
до пары центов). Кнопка «Проверить и сохранить» проверяет ключ бесплатным запросом. Ключ хранится в том же
`config.json`, что и golden_key.

### Создать лот
**＋ Новый лот** → выберите раздел. Сначала показываются ваши разделы; начните вводить название игры или
раздела, чтобы искать по всему каталогу FunPay, или введите числовой ID раздела (он есть в адресе
`funpay.com/lots/<ID>/`). Заполните форму и нажмите «Создать лот».

Совет: чтобы проверить, как выглядит лот, создайте его со снятой галочкой «Активное» — покупатели его не увидят.

### Удалить
🗑 в строке или «Удалить» в редакторе. Удаление необратимо: на FunPay нет корзины.

### Дублировать
⧉ в строке лота открывает редактор новой копии со всеми полями исходного лота (тексты, параметры, цена,
товары автовыдачи, картинки). Поменяйте, что нужно (например, «НА 3 ЧАСА» → «НА 6 ЧАСОВ» и цену), и нажмите
«Создать лот». Пока не нажали — ничего не создаётся.

### Массовые действия
Отметьте лоты галочками слева (галочка в шапке выбирает все видимые) — появятся кнопки:
- **Включить / Выключить / Удалить**;
- **Цена…** — поставить точную цену, изменить на % (например `10` или `-15`) или прибавить/вычесть сумму.
  Это цена «к получению», как в форме лота (без комиссии FunPay), округляется до 0.01;
- **Заменить текст…** — найти и заменить фразу во всех текстах выбранных лотов (краткое и подробное описание,
  сообщение после оплаты, русская и английская версии). Регистр букв учитывается.

Лоты обрабатываются по очереди с прогрессом; в конце — сколько изменено, сколько без изменений и ошибки.

### Шаблоны описаний
В редакторе лота — **📋 Шаблоны**. «Сохранить» запоминает текущие тексты (краткое/подробное описание,
сообщение после оплаты, RU и EN) под названием; «Применить» подставляет их в открытый лот. Удобно держать
своё оформление и для новых лотов, и для массовых обновлений.

### Бэкап и восстановление
**⋯** рядом с «Поднятием»:
- **Сохранить бэкап всех лотов** — читает каждый лот целиком (все поля формы) и сохраняет в `.json` через
  обычный диалог «Сохранить»;
- **Восстановить из бэкапа** — показывает лоты из файла, можно выбрать нужные. Они создаются **новыми лотами**
  (существующие не меняются), по умолчанию выключенными — проверьте и включите. Так же можно перенести лоты
  на другой аккаунт: сохраните бэкап на одном, переключитесь и восстановите на другом.

### Автоподнятие
**⚡ Поднятие** в шапке. Включите «Поднимать лоты автоматически» и отметьте разделы (по умолчанию — все).
Приложение пытается поднять лоты, FunPay отвечает «подняты» или «подождите N часов» — следующая попытка
планируется ровно на это время. В таблице видно последнюю попытку и следующую; «Поднять» — попробовать сейчас.
Разделы одной игры FunPay поднимает вместе. Рядом с кнопкой — когда следующая попытка.

Автоподнятие работает, пока приложение запущено. Чтобы закрытие окна его не останавливало, включите
**⚙ → «Работать в фоне»** (см. ниже).

## Заказы
Вкладка **«Заказы»**:
- список продаж с фильтрами **Все / Ожидают / Закрытые / Возвраты** и поиском по покупателю, номеру и лоту,
  «Показать ещё» — более старые;
- клик по заказу — карточка: параметры, сумма, отзыв. Можно **ответить на отзыв** (кнопка **✨ Черновик ИИ**
  пишет вариант ответа — нужен ключ нейросети), **открыть чат** с покупателем, **вернуть деньги**
  (с подтверждением; это необратимо, отзыв покупателя может быть удалён).

### Аренды
Вверху вкладки «Заказы» — активные аренды с обратным отсчётом. Срок берётся из названия лота
(«НА 3 ЧАСА», «НА 30 МИНУТ», «НА 24 ЧАСА»), отсчёт — от времени заказа; возвраты не учитываются.
**Добавить время конкретной аренде** можно прямо на карточке: **+30 мин**, **+1 ч** или **±…** — своё
значение в часах и минутах (там же можно убавить время или сбросить поправку). Срок по-прежнему считается
по названию лота, а добавленное время прибавляется сверху и показывается рядом со сроком («1 дн. +1 ч»).
Поправка запоминается для этого заказа; напоминания о конце аренды после изменения срока сработают заново —
в том числе если аренда уже закончилась и вы её продлили.

В ⚙ → «Аренда»:
- напоминание за 10 минут до конца и по окончании (уведомлением);
- бонусные минуты к сроку (например, 60, если даёте час за отзыв);
- **автосообщение покупателю**, когда аренда закончилась (выключено по умолчанию), с вашим текстом:
  `{buyer}` — ник, `{order}` — номер заказа.

## Чаты
Вкладка **«Чаты»**: слева — последние 50 диалогов (непрочитанные отмечены), справа — переписка.
Сообщения обновляются каждые 10 секунд. **Ctrl/⌘+Enter** — отправить. **✨ ИИ** пишет черновик ответа
по последним сообщениям; если в поле уже есть текст, он используется как подсказка («скажи, что выдам
через 10 минут»). Черновик не отправляется сам — проверьте и нажмите «Отправить».

## Аналитика
Вкладка **«Аналитика»**:
- **Продажи** за 7 / 30 / 90 дней: выручка (без возвратов), число продаж и покупателей, средний чек, возвраты,
  повторные покупатели, график выручки по дням (наведите на столбик — детали) и лучшие лоты;
- **Цены конкурентов**: выберите раздел — для каждого вашего лота видно вашу цену на витрине, место по цене
  среди похожих предложений (те же параметры раздела и тот же срок из названия; 1 — самый дешёвый),
  минимальную и медианную цену и «Дешевле всех» — 5 самых дешёвых конкурентов со ссылками. Цены — как их видят
  покупатели (с комиссией FunPay). Выключенных лотов на витрине нет — для них показан рынок того же срока.

## Язык, фон, уведомления, тема, горячие клавиши
⚙ → «Общие» и «Уведомления»:
- **Язык / Language** — русский или английский (по умолчанию — как в системе). Переключить можно и на
  экране входа (RU / EN в углу). На выбранный язык переводятся весь интерфейс, сообщения об ошибках,
  уведомления и меню значка в трее; даты и статусы FunPay тоже. Названия лотов, сообщения покупателей,
  отзывы и поля конкретного раздела остаются как на FunPay;
- **Работать в фоне** — закрытие окна не завершает приложение: на Windows оно прячется в трей (значок у часов:
  «Открыть», «Поднять лоты сейчас», «Выход»), на macOS и Linux сворачивается в Dock / панель задач.
  Автоподнятие, уведомления и аренды продолжают работать;
- **уведомления** о новых заказах, новых сообщениях и (по желанию) каждом автоподнятии — системные
  уведомления ОС плюс всплывашки в окне;
- **Тема** — как в системе, светлая или тёмная.

Горячие клавиши (на Mac — ⌘ вместо Ctrl): **Ctrl+1…5** — вкладки, **Ctrl+N** — новый лот, **Ctrl+F** — поиск,
**Ctrl+R** — обновить текущую вкладку, **Esc** — закрыть окно/панель.

## Финансы

Вкладка **«Финансы»** в шапке.

- **Баланс** — по каждой валюте (доллары, рубли, евро), как на странице «Финансы» FunPay.
- **История операций** — заказы, выводы, пополнения и прочее. Фильтры сверху, «Показать ещё» подгружает
  более старые операции. Клик по «Заказ #…» открывает заказ на сайте.

### Вывод средств
1. Нажмите **«Вывести»** под нужной валютой.
2. Выберите способ (карта, СБП, USDT TRC20 и т. д.). Под списком — комиссия FunPay для этого способа.
   Для СБП дополнительно выберите банк.
3. Укажите реквизиты. Сохранённые на FunPay реквизиты подставляются автоматически и есть в выпадающем списке поля.
4. Введите сумму (кнопка «Всё» — весь баланс). Поле «К получению» FunPay считает сам, с учётом комиссии и курса.
5. **«Далее»** — FunPay проверяет данные и показывает итог. На этом шаге деньги **не списываются**.
6. Проверьте реквизиты и суммы, при включённой 2FA введите код из приложения-аутентификатора и нажмите
   **«Вывести …»**. FunPay создаст заявку, она появится в истории операций.

Отменить заявку можно на сайте FunPay, пока она не обработана.

## Обновления

Приложение само проверяет новые версии при запуске. Если вышла новая — справа внизу появится карточка
с номером версии и списком изменений:
- **Обновить** — скачать и установить; приложение перезапустится уже новой версией.
- **Позже** — напомнить при следующем запуске.
- **Пропустить** — не напоминать об этой версии.

Перезапускать приложение, чтобы узнать о новой версии, не нужно:
- **автоматически** — пока приложение запущено (и в фоне), оно проверяет GitHub каждые 30 минут; о новой
  версии придёт уведомление и появится карточка «Обновить». Выключается в ⚙ → «Обновления»;
- **вручную** — кнопка **⟳ v1.6.2** в шапке, **⚙ → «Обновления» → «Проверить сейчас»** (там же время последней
  проверки) или пункт **«Проверить обновления»** в меню значка в трее (Windows). Ручная проверка показывает
  и версию, которую вы раньше пропустили.

Обновление ставится на место текущей версии, лишних файлов рядом не остаётся (старая копия уходит
во временную папку и удаляется при следующем запуске).

- **Windows:** если приложение лежит в папке без прав на запись (например, `Program Files`),
  переместите его на рабочий стол или в «Загрузки».
- **macOS:** если приложение запущено не из «Программ» и macOS держит его в защищённой копии,
  обновление ставится туда, откуда вы его запускали, а если это не удаётся — в «Программы».
- **Linux:** файл `FunPayLots` заменяется на месте; нужны права на запись в его папку.

> Версии до 1.2.0 не умеют обновляться — 1.2.0 нужно один раз скачать вручную.
> В версиях 1.2.0–1.3.0 на Windows после «Обновить» приложение может закрыться и не открыться само —

## Ограничения
- **Картинки** лота сохраняются как есть (в том числе при дублировании и в бэкапе); добавлять и менять их
  пока нужно на сайте. Картинки в чатах открываются в браузере.
- **Чаты** — последние 50 диалогов, как в списке на сайте; отправка картинок пока только на сайте.
- **Аренда** считается по названию лота; если срок в названии не указан, заказ в арендах не появится.
- **Разделы валюты** (игровая валюта, `/chips/…`) не поддерживаются — у них другой редактор на FunPay.

## Частые проблемы

| Сообщение | Что делать |
|---|---|
| «Ключ не подошёл» | Ключ устарел или скопирован не полностью. Возьмите свежий `golden_key`. |
| «FunPay отклонил запрос (403)» | То же: обновите ключ. Если не помогло — попробуйте позже или с другой сети. |
| «Нет связи с FunPay» | Проверьте интернет / VPN. |
| «Заполните это поле…» при сохранении | FunPay требует обязательное поле — его название указано в ошибке. |
| ⚠ у раздела в списке | Раздел не загрузился (например, удалён на FunPay). Его можно убрать кнопкой «Убрать раздел из списка». |
| «Ключ Anthropic не подошёл» | Проверьте ключ в ⚙: он начинается с `sk-ant-` и не должен быть отозван. |
| «На аккаунте Anthropic закончились средства» | Пополните баланс в console.anthropic.com → Billing. |
| «Дневной лимит бесплатного перевода исчерпан» | Подождите до завтра, укажите почту в ⚙ или добавьте ключ нейросети. |
| «Нейросеть отказалась писать такой текст» | Переформулируйте вводные проще и конкретнее. |
| «Неверный код 2FA» при выводе | Введите свежий код: он меняется каждые 30 секунд. |
| «К получению» показывает «—» | Для некоторых способов FunPay считает сумму только после ввода реквизитов. Заполните их. |
| Не удаётся обновиться | Переместите приложение в папку с правами на запись или скачайте новую версию со страницы Releases. |
| Окно пустое (Windows) | Установите [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/). |
